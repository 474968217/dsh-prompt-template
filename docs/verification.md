## 单层标签 / Flat tags

2026-11-26：按用户要求合并分类与标签为一个标签维度。模板 canonical 数据仅有 `tags: string[]`；管理器标签多选 OR，再与 query AND。候选始终从全库收集；编辑器支持自由输入、Enter/添加、已选 chip 移除，保存会一并校验和提交待输入文本。标签最多 6 个、每个 20 字符，trim 并忽略大小写去重。旧 tags 顺序与首次拼写优先，旧 category 含逗号时作为单个原子标签附后，不拆分。

存储域改为 v2、`compatibleVersions: [1]`。已初始化旧库的纯读取只在内存转换，不改写介质、不增加 revision；首次成功正常 mutation 写入全库 canonical tags-only/v2，旧 v1 reader 拒绝读取。真实 JSON 介质测试由独立进程冷读验证这条边界；未直接迁移运行中的宿主模板库，不覆盖用户内容或恢复已删默认项。

本轮最终语法检查通过，全量 76/76 测试通过、无跳过（20 项客户端、56 项其他测试）。独立 review 发现「待输入 Review → 选择同名候选 → 移除 chip → 保存」会从待输入中复活标签；新增回归先复现失败，再修复为选择候选时同步消费同名待输入，回归及全套测试通过。独立 review 最终复核已完成：原 P2 已修复，未发现新问题；独立客户端 20/20 回归与额外纯 helper 边界检查通过，无浏览器视觉结论。客户端测试为纯逻辑，未操作或模拟浏览器 UI，不证明当前安装页面的布局、原生事件、主题及焦点行为。

本轮 `npm pack --dry-run` 确认 14 个文件齐全。已对 linked 插件调用 `set_plugin enabled:true` 触发重组，返回 `application: applied`、`changed: false`；重组时仍有既有 cua 缺少 binary 的警告。该结果表示宿主重组已应用，不能据此认定浏览器已加载本轮新 UI 或交互验收通过。
