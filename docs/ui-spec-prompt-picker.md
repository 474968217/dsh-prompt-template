# 提示词模板交互规格

本文件描述当前实现目标，替代早期方案稿。`mockup/` 下的静态稿保留用于理解设计过程，不作为真机验证。实际运行证据见 [验证记录](verification.md)。

## 入口

- 输入框工具栏左侧，B1「文档图标 + 提示词」描边按钮，order 10。
- 高 28 px，中文最小宽 76 px、英文最小宽 84 px。文字常驻，便于与已有第三方图标按钮区分。
- 默认、悬停、打开、禁用、键盘焦点均有可区分状态。跟随 DSH 主题，不引入品牌强调色。

## 选择浮层

- 通过 portal 挂到 body，围绕触发器定位，窗口滚动或变化时重新计算。目标宽 408 px，小屏限制在视口内。
- 打开前捕获输入框的选区与草稿 revision，随后搜索框获得焦点。
- 搜索覆盖标题、正文、分类和标签，搜索不修改原模板。
- 「本项目」「全局」分组。不匹配当前工作目录的项目模板不可见，管理面板仍可管理完整模板库。
- 置顶优先，同组维持手动顺序；内部记录最近使用时间，不显示使用次数。
- ↑ / ↓ 到边界停止；Enter 插入；Esc 关闭；IME 组字期间不响应插入或关闭快捷键。键盘选择项需滚动到可见区。
- 点击模板仅做一次可撤销纯文本插入，不发送。选中的原文由插入动作替换；空草稿也使用相同 API。
- 草稿变化或不可编辑时关闭浮层并给出错误，不覆盖草稿。重新打开可捕获新插入位置。
- 读取中、空库、搜索无结果、读取失败各有明确反馈；失败提供重试。底部始终提供「管理模板…」。

## 管理面板

- 自建遮罩面板，不依赖插件设置页路由；portal 到 body，模态语义、焦点环与背景滚动锁。
- 左侧显示完整模板库，搜索与工具操作分行，数量不拆行。支持关键词搜索与分类、标签勾选筛选：同一维度多选取并集，不同维度及关键词间取交集，可一键清除筛选。
- 左侧行只负责选择与排序：选中行以边界、内侧标记和箭头标识，置顶图标只显示状态。行首拖拽手柄显示插入落点；保留键盘移动途径。筛选时仅调整当前可见项所占的顺序槽位，隐藏项位置不变；向宿主提交完整 id 列表，复用 revision 冲突保护。
- 右侧固定标题区显示当前模板名称，置顶与删除以文字按钮集中在该区，不再悬浮在列表行上。删除确认紧接标题区，明确模板名称和不可恢复说明；有未保存修改时说明这些修改也会删除。
- 编辑区由固定标题、可滚动表单、固定底栏组成。底栏左侧为保存状态，右侧为取消与保存；放弃修改确认单独成条。分类与标签、使用范围分别分节，校验错误与对应输入关联。
- 最大面板 1080×760 px，左栏 304 px；800 px 以下左栏收窄至 264 px，640 px 以下切换单栏列表/编辑视图。返回列表仍经过未保存保护，Tab 焦点循环只包含可见控件。
- 右侧表单：标题、正文、分类、逗号分隔标签、生效范围、项目多选、置顶。分类和标签从完整模板库收集去重候选，可快捷选择；仍可手动输入新值，不受当前列表筛选影响。标签快捷选择不重复添加且遵守最多 5 个的限制。
- 生效范围采用原生单选框切换全局/指定项目；项目用 A 方案的勾选标签多选，选中态同时具备复选勾、主题强调描边和加粗文字，并显示已选数量。点击区至少高 44 px，长名称换行，键盘焦点有独立外环。修改仅进入编辑草稿，保存后才持久化，设计演示状态不写入配置。项目为空时阻止保存并说明原因，不静默扩大为全局。
- 同名允许存在，以 id 区分。限制：标题 60 字符、正文 20000 字符、分类 20 字符、最多 5 个标签且每个 12 字符、最多 20 个项目。
- 校验与网络错误行内显示；保存期间禁用重复提交，失败保留输入。成功后更新列表与当前快照。
- 删除使用标题区下的二次确认带。切换模板、新建、返回列表、关闭、Esc、遮罩点击均需保护未保存内容；用户明确放弃后才清除。
- 并发版本冲突明确提示，提供刷新列表而保留当前编辑的处理路径，不自动覆盖另一会话修改。

## 项目语义

项目取会话工作目录，不使用工作区显示名作为唯一标识。目录规范化后精确匹配，Windows 忽略大小写，不继承子目录，不同 worktree 视为不同目录。编辑时可选择当前目录、已登记目录以及已存模板引用目录。项目范围用于显示过滤，不构成权限隔离。

## 本地化与资源

所有可见文案支持中文、英文，并订阅语言变化。样式使用运行时已提供的 DSH 主题 token。React 与 react-dom 来自平台模块表。apply 创建的样式、locale、槽位与事件监听随上下文卸载清理。

## 版本边界

v0.1 不实现变量替换、Markdown 预览、导入导出、斜杠触发和全局快捷键。首次空库添加 6 条全局工程提示词，调试、审查、验收三条置顶，全部可编辑删除；升级不自动增补已有库，删除后不自动复活。
